Find the right symbol, special letter or complete emoji, then type it with a tap. Uniboard is an offline Unicode character explorer and custom keyboard for iPhone and iPad.

FIND IT YOUR WAY
- Search official character names, aliases, descriptive annotations or block names. Try "arrow", "heart" or "Greek".
- Look up hex code points such as U+1F680, 0x1F680 or 1F680, or use decimal:128640. Paste a character into the app's search to identify it.
- Browse the complete Unicode block list and scroll through assigned characters, from math symbols and punctuation to scripts and phonetic marks.

EXPLORE COMPLETE EMOJI
- Search and browse the official fully qualified emoji set, including joined emoji, skin tones, flags and keycaps.
- Copy or insert the complete sequence, preserving joiners and variation selectors. Inspect every component's name and code point.
- Emoji order uses the version that introduced the emoji, shown separately from its components' Unicode ages.

CHOOSE YOUR UNICODE EDITION
- Switch between Unicode 18, the latest release, and the Unicode 19 development draft. Both catalogs are bundled for offline use; the draft is selected by default.
- Discover characters across the catalog with the newest Unicode age first. Choose oldest first or code point order whenever you prefer.
- The app and keyboard remember their own edition and order choices.

TYPE AND UNDERSTAND
- Enable the Uniboard keyboard, search with its own keys, then tap a character or emoji to insert it at the cursor. The search query stays inside the keyboard.
- Hold a key, or pause a pointer over it, to read its name, description, code points and properties without inserting it. Details include Unicode age, block, category, script, bidirectional class, combining class, decomposition and UTF-8 bytes where applicable.
- Use the top-right backspace, including press-and-hold deletion, plus space, return and the globe menu.
- Keep favorites and recent entries locally. The app and keyboard keep separate collections. Copy entries or combine text in the app's scratchpad.

Search Unicode section names and informative notes as well as stable official names. For example, “Suzhou numerals” finds the characters officially named “Hangzhou numeral”; details retain the original name and explain the historical naming issue. Read typed aliases, related characters and numeric properties where Unicode supplies them.

PRIVATE AND OFFLINE
No account, ads, analytics SDK or keyboard Full Access. Uniboard does not send your typing or searches to a server.

Enable the keyboard in Settings > General > Keyboard > Keyboards > Add New Keyboard > Uniboard. While typing, hold the globe key to switch to it.

Draft names and assignments may change. Character and emoji display depends on iOS fonts; some entries may appear as boxes or separate glyphs. Names, descriptions and properties remain readable. Preview markers for invisible characters and combining marks are not inserted.

The interface, Unicode names and descriptions are in English. iOS uses its own keyboard in password and phone-number fields, and some apps disable custom keyboards.

Requires iOS 17 or later.
