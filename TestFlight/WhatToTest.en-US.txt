SEARCH AND SAVE TOUCH FIXES
Search uses four rows of normal-height query keys. Portrait results scroll horizontally above the keys; iPad and landscape put results beside them. Result keys stay fully visible and full height. Check rotations and visible host content.

Both Delete keys edit before the local search caret. Test empty/start/middle/end, repeated/held Delete, outside releases, inspection and Done/reopening. Query deletion must never alter the receiving app. Done restores host typing and host Delete while keeping the query. Cancellation must stop repeats.

Properties has a native 76x44pt Save key. Test center/corners, cancel and save; preserve query/caret/receiving text. Hold a result to inspect without inserting. Check unsupported glyphs and emoji.

FIXED DAILY KEYBOARD
The number row is always present. Digits, letters and footer share one height (+15%). No resize controls. App Settings controls the optional symbol/search bar. At most one optional top bar; rounded keycaps stay fully visible. The U key toggles the toolbar. Fonts, Unicode version, layouts and key mappings are app-only. Keyboard ... contains Order only while the Unicode picker is available.

GESTURES AND SHIFT
Hold: current-case accents. Up: mapped symbols plus unused macOS Option outputs. Down: opposite case then its accents. Defaults are unique across groups, including I/O currency choices. Keep pressing to switch Hold > Up > Down > Up, then slide sideways; release inserts once. Choices surround the primary: 7,5,3,1,2,4,6. Test edge keys, exact combining text and cancellation.

Shift matches normal typing: tap for one capital, double-tap for Caps Lock, touch Shift then slide to a letter for one capital. A stationary hold is one Shift tap. Cancelled/outside slides must not insert or leave Shift stuck.

IPAD AND CUSTOM KEYS
Check portrait/landscape, Tab/Caps/both Shift keys, gray modifiers, one blue Return and two controls right of Space. Landscape presets: iPad, compact ANSI, full ANSI. Manual Shift changes punctuation; Caps Lock and automatic capitals keep digits literal. Symbol pages avoid duplicate digits. Mappings: standard, iPad, macOS Option, Off. Customize Tap, Shifted tap, Hold, Up and Down independently. Test literal emoji, combining text, Off, failed saves and Full Access OFF.

PAGES, FAVORITES AND PRIVACY
Star opens the preferred page and returns to QWERTY. Swipe across ALL pages and Recent, one page at a time, preserving U visibility. Hold Star to create, rename, reorder or delete pages and choose a preferred target. Recent and saved symbols use plain keycaps. Editors stay inside the keyboard.

Saved shares built-in Favorites. App edits reach the keyboard with Full Access OFF; keyboard edits wait locally until optional Full Access permits writing back. Test both directions, removal, concurrent edits, relaunch and unavailable storage without data loss. Custom pages and Recent stay local. Typing, queries and favorites are never sent over a network. Check visual touch feedback; physical iPhone haptics require Full Access.

Unicode 18 defaults; 16/17 previous, 19 DRAFT. Search names, blocks, descriptions, code points and Suzhou numerals. Verify exact whole-emoji insertion and sharp search text in light/dark and Reduce Transparency.
