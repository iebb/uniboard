Uniboard 1.1 brings everyday English typing and a more personal Unicode keyboard.

- Literal QWERTY with a permanent number row, taller keys, Shift/Caps Lock, accents, symbol layouts and repeating Backspace.
- One optional symbol bar or search bar, controlled in app Settings. U shows or hides Unicode controls. The old resize handle and height preview are removed.
- Full-height search keys, clear text and precise cursor editing. Both Backspace controls edit the search query while search is focused. Returning to typing preserves the query and results.
- Larger, more reliable Save controls in Unicode properties, and fully visible result keycaps without edge fading.
- Favorites-first Star switching and horizontally swipeable symbol pages, including every saved page and Recent. Create, rename, reorder and edit pages inside the keyboard. Saved and Recent use matching keycaps without code-point labels.
- Independent Tap, Shifted tap, Hold, Up and Down mappings for character keys. Default Up offers symbols, Down changes case, and Hold offers accents. Switch groups and select sideways without lifting; default candidates are unique.
- iPad modifier keys and configurable landscape ANSI layouts, with Numbers/Symbols and Hide Keyboard to the right of Space.
- Local Favorites sharing between the app and keyboard. Optional Full Access allows keyboard Favorites to sync back and enables light iPhone haptics; typing and searches are never collected.
- Optional Noto-first font downloads for historic scripts, symbols and rare Han, measured on iOS 27. A tiny bundled font fixes dotted-circle combining previews. Download only in the app; verified fonts work offline in the keyboard without Full Access.
- Unicode 18 release by default, previous releases 17/16 and optional Unicode 19 DRAFT. Edition and optional fonts are set only in the app.
- Ascending code points by default, whole-word search priority, block-name search and "Suzhou numerals" aliases.

No account, autocorrect or word predictions. All Unicode catalogs and search work offline.
