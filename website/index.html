A practical guide to Unicode search ↗

A few useful answers

Before you type.

How do I add the Unicode keyboard on my iPhone or iPad?

Open Settings → General → Keyboard → Keyboards → Add New Keyboard, then choose Uniboard. In a text field, hold the globe key and select Uniboard. You can leave Full Access off: typing, search and text inspection work without it. Copying to the clipboard from the keyboard needs Full Access. See the setup guide.

Can I search by Unicode code point?

Yes. Try U+1F680, 0x1F680 or 1F680 for 🚀. Explicit decimal search uses decimal:128640. Use U+FACE for a hexadecimal code point containing only letters.

Does every Unicode character display on iOS?

No font contains every character. Your device may show a missing-glyph box for a character even though its code point is valid. Recent characters and emoji may need newer fonts. Hold a key or keep a pointer over it to read the name, description and properties even when the glyph is missing. Uniboard copies or inserts the original scalar or complete emoji sequence. Downloaded fonts and font rules change only Uniboard’s previews; other apps choose their own fonts.

How do complete emoji and Unicode versions work?

The Emojis tab searches and browses the official fully qualified emoji set. Tapping a keyboard entry inserts its entire sequence, including any joiners, variation selectors or modifiers. The latest Unicode release is the default; you can also choose either of the two previous releases or the development draft. Then choose newest, oldest or code point order. Emoji version order uses the emoji’s introduction, while character order uses Unicode age.

Can I use it in every text field?

iOS uses its system keyboard in password and phone-number fields, and some apps disable third-party keyboards. In other supported fields, switch with the globe key. You can also copy characters from the containing app.

Is Uniboard available in languages other than English?

The app interface and Unicode character names are in English. The catalog contains characters from many writing systems; inserting those characters does not require an English document. You can also type Japanese with romaji and Mandarin Chinese with pinyin after an optional language download in the app.
