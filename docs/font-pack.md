# Optional preview fonts

Extra Unicode fonts defaults off and is controlled only in the companion app. The same setting and downloaded files reach the keyboard through its local App Group; reading them does not require Full Access. The keyboard contains no downloader. Disabling the setting clears fallback caches. Native-supported text, interface/editor fonts and every emoji iOS draws completely retain Apple's renderer. Each preview is shaped with the stock fonts first; only text that hits glyph zero or LastResort, or an emoji sequence that shapes to more glyphs than visible characters, is retried with a fallback. Color emoji candidates must also leave ink in a test render, so a format the runtime cannot paint is rejected. Previews still missing after fallback are tinted red in the app and keyboard. Insertion always uses original Unicode text; receiving apps choose their own fonts.

Four preview fonts download on demand as the first pack, Preview basics, from the `fonts-1.1-20261022` release; none is bundled: unchanged Noto Sans Symbols 2 v2.008, GNU Unifont 18.0.01, GNU Unifont Upper 18.0.01, and the 27,528-byte derived Uniboard Combining Previews face. Together they total 11,706,408 bytes. `Fonts/manifest.json` pins exact source versions, sizes, hashes, ranges and notices. The 76,732-scalar cmap union is not additional coverage beyond any particular iOS release. The derived face improves complete combining clusters without adding new scalar coverage.

App Settings → Font Downloads offers six independent, removable packs: historic scripts and symbols (13.9 MB), rare Han B–F & I (30.9 MB), rare Han G, H & J (7.5 MB), Seal script (5.8 MB), emoji previews (10.8 MB) and ConScript (UCSUR) (3.2 MB), which is the unchanged Fairfax HD from Kreative Korp's open-relay repository at a pinned commit, OFL-licensed, covering the Private Use ranges of the ConScript Unicode Registry. Uniboard ships only the registry's block ranges and names (`Shared/UCSUR.swift`), not its character names. The historic and Han packs are measured-gap subsets: Noto first, then Jigmo and Fairfax HD for uncovered ranges. Nothing is downloaded unless the user requests a pack, and downloading one turns Extra Unicode fonts on. Packs download one at a time in request order; Download All queues every incomplete pack. Within a pack at most three files download concurrently, with combined progress. Cancelling the active or a waiting pack keeps completed files; retry downloads missing files only. Downloads survive navigation within the app and are excluded from backups.

The app makes cookie-free static requests to the pinned GitHub release CDN. No typing, search terms, favorites or scratchpad contents are included. Each response is bounded by its expected size and SHA-256 verified before atomic local publication. Files are never globally registered or installed as system fonts. Receipts prevent incomplete or modified files from being opened. The resolver keeps at most four CGFont files and 2,048 text choices cached; download revisions invalidate choices without resetting the query or active page. Memory warnings clear the font cache.

The resolver first shapes the complete production preview with UIKit/Core Text. Only missing scalars trigger a candidate lookup; real outlines and complete-cluster shaping are both required. This prevents a mark's cmap entry from being advertised as recovery when the dotted-circle preview still shows tofu. The bundled derived face repairs 86 such clusters using real source outlines.

The [native iOS 27 audit](font-audit/README.md) tested 172,351 visible scalar previews. Stock fallback missed 100,502; with all optional packs, 83,735 recover and 16,767 remain unsupported. The report names remaining blocks and documents simulator/runtime limits. Names, descriptions and properties work independently of glyph availability. Unicode 19 draft assignments may exceed font coverage.

Bundled/source license notices are shown in app Settings → Font Licenses. Noto and Fairfax derivatives carry their SIL OFL notices and unreserved names; Jigmo carries CC0 plus attribution. Build scripts pin source hashes and reproduce byte-identical assets; `Scripts/validate_fonts.py` checks the manifests, outlines, diagnostic-box exclusions, licensing, baseline gaps and size budgets. The monthly catalog refresh preserves this pinned font set and does not infer support for newly assigned characters. No iOS 18.5 validation is required for this release.
