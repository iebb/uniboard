Uniboard is an offline English and Unicode keyboard for iPhone and iPad. No account or network is needed. The interface is English. Full Access is optional.

1. Add Uniboard in iOS Settings > General > Keyboard > Keyboards > Add New Keyboard. In Uniboard > Settings > Try your keyboard, focus the editor and hold the globe to choose Uniboard.

2. The daily keyboard uses literal QWERTY without autocorrect or predictions. Its fixed template always includes digits, three letter rows and a matching footer. Phone/narrow keys are 41.4pt and wide iPad keys 59.8pt, 15% taller. App Settings offers Show symbol bar and, while enabled, Show search bar instead. Only one optional top row appears; replacing its contents keeps the same height. Symbols use normal rounded keycaps and scroll horizontally. There is no resize handle, dragging, height preview, triangle or saved height.

3. Tap Shift for one capital, double-tap for Caps Lock, or touch Shift and slide to a letter. Hold a letter for current-case accents; Up offers opposite-case forms; Down mapped digits/symbols plus unused macOS Option choices. Defaults do not repeat across groups. A vertical flick keeps its first choice; slide sideways to select others. Currency-key holds keep their currency family. Check punctuation, double-Space, Return and repeating Backspace. Symbol pages avoid repeating the normal digit row.

4. U opens Unicode browsing; U/ABC returns to English. Search U+1F680 and insert the rocket's original scalar. Search supports names, descriptions, blocks, code points and complete emoji. Move the query cursor and edit its middle: query text must never reach the host. Suzhou numerals finds U+3021 HANGZHOU NUMERAL ONE with its naming note. Hold/hover a browse tile to inspect names, descriptions, version, category, script and encoding without inserting. Unsupported glyphs retain their properties. Emoji insertion preserves whole sequences.

5. Star beside Space opens the preferred symbol board (Favorites by default) and returns to QWERTY. Hold it to switch/manage boards. Symbols is included. Saving a character/emoji asks for its board. Hold board keys for variants, Inspect or Edit. Configuration uses a bounded opaque panel and does not type into the host. Temporary selection preserves the Star preference; deleting its custom target falls back to Favorites. Saved/Recent have rounded keys without code-point captions.

6. Only app Settings selects Unicode version, optional offline fonts, collapse, top-bar layout, iPad presets and per-key gestures. Unicode 18 release is default; 16/17 are previous releases, 19 is DRAFT. iPad supports stock-style modifiers plus digits, and compact/full ANSI in landscape. Numbers/Symbols and Hide sit right of Space. Tap, Shifted tap, Hold, Up and Down can be configured independently. Exact combining text and emoji stay literal. Keyboard … contains only Order and Open companion app, with Home Screen guidance if iOS rejects opening.

No typing, queries, accounts or analytics are collected. Shared on-device files contain app settings, configured keys and explicit Favorites, never document typing or queries. With Full Access OFF, app favorites reach the keyboard and keyboard edits stay pending locally. Optional Full Access permits writing those Favorites back to Saved and light iPhone haptics. It does not enable network collection. Custom boards, recents and scratchpad remain local. Receiving apps handle inserted text. iOS uses its own keyboard in secure/phone fields; some apps disable custom keyboards.
