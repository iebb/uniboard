# Uniboard icon

The master is `Uniboard-Icon.png`. The built-in image generation tool produced the artwork; `swift Scripts/generate_icon.swift` normalizes it to the opaque 1024 × 1024 App Store asset. The symbol keeps the application's forest, ivory and terracotta identity, with a large U+ mark that reads at home-screen sizes. iOS supplies the outer corner mask.

## Generation prompt

Use case: logo-brand. Asset type: production iOS App Store app icon for Uniboard, an offline Unicode character search keyboard. Create one exceptional square icon, viewed straight on, full-bleed opaque background, ready for a 1024-by-1024 iOS asset. Develop the existing app's warm ivory, deep forest ink and restrained burnt-orange identity into a memorable, confident typographic symbol. A single oversized warm-ivory rounded geometric U, beautifully drawn with a substantial stroke, balanced proportions and crisp negative space, combined with a compact burnt-orange plus sign at its upper right: the recognizable Unicode U+ idea. The U subtly feels like a tactile keyboard key through a beautifully restrained recessed curve and precise soft edges, but remains extremely simple and reads instantly at 32 pixels. Deep forest-green background with very subtle tonal depth; warm ivory monogram; burnt-orange plus. Swiss typographic precision, premium independent developer tool, minimal sculptural depth, quiet sophistication. Center the monogram composition with generous but efficient breathing room; the mark should occupy roughly 72 percent of the icon canvas. No wordmark, no UNIBOARD text, no microscopic code points, no decorative glyph collage, no magnifying glass, no sparkles, no extraneous objects, no mockup device, no outer rounded corners, no border, no transparent pixels, no glossy plastic, no watermark. Output only the single finished square app icon.
