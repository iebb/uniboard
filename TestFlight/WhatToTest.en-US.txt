Uniboard 1.1 beta. Public release awaits device approval.

FIXED KEYBOARD TEMPLATE
The number row is always present in normal typing. Phone/narrow keys are 41.4pt; wide iPad keys are 59.8pt (+15%). Digits, letters and footer share one height. There is no resize grip, dragging, saved height, triangle or preview.

App Settings > Keyboard layout: Show symbol bar; Show search bar instead. The second switch appears only while the first is on. Replacing symbols with search keeps the same height. Check a fully visible, opaque symbol strip with rounded keycaps and horizontal scrolling. Scrolling must not insert. Empty selected pages use the stock strip without changing the preferred Star page. Test both switches, relaunch and Full Access OFF.

LETTER GESTURES AND SHIFT
Hold: accents in the current case. Up: mapped digit/symbol plus unused macOS Option outputs. Down: opposite case first, then accented forms. Each default candidate belongs to only one group per key. With digits visible, I and O start with £ and ¥, without repeating currency families; actual currency-key holds keep their family.

Keep pressing to switch Hold > Up > Down > Up; reversing direction changes groups without crossing the original key. Slide left/right for choices; lift inserts once. Choices surround the primary: 7,5,3,1,2,4,6. Test I/O, screen edges, Shift, cancellation, rotation and exact composed/decomposed text.

Shift: tap for one capital, double-tap for Caps Lock, or touch Shift and slide to a letter for one capital. Stationary holds act as one Shift tap. A cancelled/outside slide must neither insert nor leave Shift stuck. Test one insertion per release, normal taps afterward and remapped Shifted tap outputs.

IPAD AND CUSTOM KEYS
Check portrait and landscape number rows, stock-style Tab/Caps/Shift, gray modifiers, one blue Return and two controls right of Space. Landscape presets: iPad, compact ANSI and full ANSI. Manual Shift changes ANSI punctuation; Caps Lock and sentence capitals keep digits literal. Symbol pages avoid repeated digits. App-only mapping: standard, iPad, macOS Option or Off.

Customize keyboard keys: independent Tap, Shifted tap, Hold, Up, Down. Test literal emoji, combining text, Off, failed saves and Full Access OFF. Explicit candidates take priority; stored mappings are not rewritten. Query editing never reaches the host.

PAGES, FAVORITES AND FEEDBACK
Star opens the preferred page and returns to QWERTY. Swipe horizontally across ALL pages and Recent, one page per swipe. Opening pages preserves U/search visibility. Hold Star to edit pages; New page has local keycaps and Add inside the keyboard. Test create/rename/reorder/delete, visible-page deletion, empty pages, preferred target and exact variants. Saved/Recent show rounded keycaps without code-point captions. Editor controls must remain in a bounded opaque panel.

Saved shares built-in Favorites. App edits reach the keyboard with Full Access OFF. Keyboard edits wait locally until optional Full Access permits writing back. Test both directions, removal, concurrent saves, relaunch and unavailable storage; failures must keep local data. Custom pages and Recent remain local. Nothing is sent over a network.

Keys highlight on touch and clear on release/cancel/scroll/rotation. On a supported physical iPhone with Full Access, verify light key-down haptics, without a held-Delete repeat stream.

UNICODE SEARCH
U opens Unicode browsing. Test query cursor positioning, middle insertion/deletion, sharp text in light/dark and Reduce Transparency, retained results and exact whole-emoji insertion. Unicode 18 release is default; 16/17 are previous releases and 19 is DRAFT. Fonts/version/collapse are app-only. Keyboard … shows Order only with the Unicode picker. App search uses the in-keyboard Done key; no floating accessory confirmation. Search names, blocks, descriptions, code points and Suzhou numerals. Inspect unsupported glyphs without inserting.
