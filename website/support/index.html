Help & support

Find your character.
Make it yours.

Uniboard is a Unicode and emoji keyboard for iOS and iPadOS 17 or later. The interface, character and emoji names, and descriptive annotations are in English.

Enable the Unicode keyboard

  1. Open Settings → General → Keyboard → Keyboards.
  2. Choose Add New Keyboard… → Uniboard.
  3. You can leave Allow Full Access off for typing, offline search and text inspection. Clipboard actions in the keyboard need Full Access; see below.
  4. In a text field, hold the globe key and select Uniboard.
  5. Tap U to open search, use the search letter and number keys, then tap a result to insert its original character or emoji sequence into your text. Tap U again to close search.

To try it inside the app, open Settings → Try Your Keyboard, tap the editor, then select Uniboard with the globe key.

Search examples

  • U+1F680, 0x1F680 or 1F680 finds 🚀.
  • decimal:128640 finds the same scalar by decimal value.
  • infinity searches Unicode character names.
  • arrows searches a block name as well as names and annotations.
  • A literal character searches for that character in the containing app.

A bare hexadecimal query must include a digit. For a letters-only code point, use a prefix, such as U+FACE. See the Unicode search guide for more examples.

Browse emoji and choose a Unicode version

Open Emojis to find complete sequences, including joined emoji, skin tones, flags and keycaps. Searching head shaking horizontally finds a sequence containing a smiley, a joiner, an arrow and a variation selector. One tap on the keyboard inserts the entire sequence.

The latest Unicode release is the default. In the app’s Unicode settings, you can also choose either of the two previous releases or the development draft. These editions work offline, and the edition setting applies to both the app and keyboard. Newest first orders characters by official Unicode Age and emoji by their Emoji introduction version. You can also choose Oldest first or Code point.

Inspect before you insert

Hold a character or emoji key, or keep a pointer over it, to open a scrollable properties panel without insertion. Read the name, description, code points, Unicode age, category, UTF-8 bytes and other available properties; emoji also show their component names. Choose Back to return, or Save to keep a favorite.

The top-right backspace edits text in the app you are typing into, even while search is open. The lower backspace on the search keys edits only your query. Hold either backspace to repeat deletion in its own destination.

Type a search key without changing your query

Tap a search letter, digit or punctuation key to edit the query. Hold that key for 0.4 seconds to insert its displayed character into your text once, leaving the query unchanged. Releasing it does not insert again. This is different from holding a result tile, which opens its properties.

A character looks like a box or dotted circle

The fonts on your iOS version may not include the glyph, and a complete emoji may render as several symbols. Hold or hover to read the name, description and properties even when the glyph is missing. A dotted circle helps show a combining mark; invisible-character markers are preview aids. Copying or inserting uses only the original scalar or complete emoji sequence.

Preview fonts and font rules

In Settings → Font Downloads, add a local font file or download a font. The Google Fonts catalog is searched locally; downloading a selected font fetches its file from Google’s font repository on GitHub. Downloads need an internet connection. Fonts are used locally by Uniboard, not installed system-wide, and other apps still choose their own fonts.

Turn on Extra Unicode Fonts to use preview fonts and font rules; it is off by default. In Settings → Font Rules, assign fonts to a code point, range or Unicode block. Code-point rules take priority over ranges, and narrower ranges over broader ones, followed by block rules. If a font is unavailable or cannot draw the text, Uniboard falls back to another matching font or its defaults. These preview settings apply to the app and keyboard without Full Access and do not change inserted text.

Copy the preview as an image

Use Copy Image to keep the preview’s appearance as a PNG. Choose text and background colors, including a transparent background, and a 1×, 2× or 3× scale. Copying from the keyboard requires Full Access. The picture is not editable text and can only be pasted where the receiving app accepts images.

Inspect the text preview

Enable Settings → Text Preview, then choose Inspect Text in the keyboard preview. It freezes and analyzes only the shown excerpt of text made available by the app you are typing into—not the whole document. See grapheme-cluster, code-point and UTF-16 counts, character details and normalization information. Inspection is local and read-only: it does not rewrite your text or send the excerpt to a server, and closing the panel clears its snapshot.

Inspection and typing work without Full Access. The inspector’s Copy Text and Copy Code Points actions write to the clipboard only when you choose them and require Full Access in the keyboard.

Save or replace your configuration

Open Settings → Configuration to export a TOML file or import one from Files. Exports include settings, layouts, pages, favorites, custom key text, font references and rules, and Copy Image options. Favorites and custom text may be personal: check the file before sharing. Typing history, scratchpad text and font files are not included. Copy Image colors and scale chosen in the keyboard without Full Access are also excluded. Your chosen Files or sharing destination may store or cloud-sync the file under its own rules.

Imports are validated for review before you confirm Replace Configuration. This replaces rather than merges: missing sections reset to defaults. Fonts are not downloaded automatically; unavailable-font rules are kept and use fallback fonts. Undo Last Import restores the locally saved previous configuration and also replaces changes made since that import.

The keyboard is unavailable in a text field

iOS uses its own keyboard for password and phone-number fields. Some apps also disallow custom keyboards. In those cases, copy a character from Uniboard and paste it where the other app permits.

Pages, favorites and Full Access

Pages and favorites you set up in the app reach the keyboard through local shared storage, even without Full Access. Favorites saved in the keyboard write back to the app with Full Access; without it, those changes remain pending locally. Recently Used stays separate. This is on-device sharing, not an Uniboard cloud-sync service.

Full Access also enables the keyboard’s clipboard actions and light haptics on supported iPhones. It is not required for typing, offline search, preview fonts or read-only text inspection.
