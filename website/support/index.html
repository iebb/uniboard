Help & support

Find your character.
Make it yours.

Uniboard requires iOS or iPadOS 17 or later. The interface, character and emoji names, and descriptive annotations are in English.

Enable the Unicode keyboard

  1. Open Settings → General → Keyboard → Keyboards.
  2. Choose Add New Keyboard… → Uniboard.
  3. Leave Allow Full Access off. Uniboard works offline.
  4. In a text field, hold the globe key and select Uniboard.
  5. Search using the keyboard's letter and number keys, then tap a character or emoji to insert its original text at the cursor.

To try it inside the app, open Setup → Try your keyboard, tap the editor, then select Uniboard with the globe key.

Search examples

  • U+1F680, 0x1F680 or 1F680 finds 🚀.
  • decimal:128640 finds the same scalar by decimal value.
  • infinity searches Unicode character names.
  • arrows searches a block name as well as names and annotations.
  • A literal character searches for that character in the containing app.

A bare hexadecimal query must include a digit. For a letters-only code point, use a prefix, such as U+FACE. See the Unicode search guide for more examples.

Browse emoji and choose a Unicode version

Open Emojis to find complete sequences, including joined emoji, skin tones, flags and keycaps. Searching head shaking horizontally finds a sequence containing a smiley, a joiner, an arrow and a variation selector. One tap on the keyboard inserts the entire sequence.

Use the edition menu to choose Unicode 18 latest release or the Unicode 19 draft. Both work offline; the draft is the default. Newest first orders characters by official Unicode Age and emoji by their Emoji introduction version. You can also choose Oldest first or Code point. Edition and order settings are remembered separately in the app and keyboard.

Inspect before you insert

Hold a character or emoji key, or keep a pointer over it, to open a scrollable properties panel without insertion. Read the name, description, code points, Unicode age, category, UTF-8 bytes and other available properties; emoji also show their component names. Choose Back to return, or Save to keep a favorite.

The backspace key is always at the keyboard’s top right. Hold it to delete repeatedly. During search, it edits the local query. Close the search keys with Done to use space, return and backspace in the host document.

A character looks like a box or dotted circle

The fonts on your iOS version may not include the glyph, and a complete emoji may render as several symbols. Hold or hover to read the name, description and properties even when the glyph is missing. A dotted circle helps show a combining mark; invisible-character markers are preview aids. Copying or inserting uses only the original scalar or complete emoji sequence.

The keyboard is unavailable in a text field

iOS uses its own keyboard for password and phone-number fields. Some apps also disallow custom keyboards. In those cases, copy a character from Uniboard and paste it where the other app permits.

Favorites in the app and keyboard are different

The app and extension keep their own collections. This lets the keyboard work without Full Access or a shared cloud account. Characters, emoji and version preferences stay local to each app or keyboard. Hold a key to inspect or save it.
