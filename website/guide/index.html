The Unicode search guide

The right symbol.
Without the hunt.

Unicode assigns code points to characters. Uniboard helps you find an individual scalar, inspect it and insert it with an iPhone or iPad keyboard.

Search by character name or description

Try an English Unicode name such as infinity, Greek small letter pi or rightwards arrow. Search also considers the catalog's aliases and descriptive annotations. Results depend on the source data; they are not generated by AI.

Search by code point

The familiar U+ notation uses hexadecimal. For example, U+03C0 identifies π and U+1F680 identifies 🚀. Uniboard also accepts a 0x prefix and bare hexadecimal queries containing a numeric digit. For letters-only hex, keep the prefix: U+FACE.

For explicit decimal search, write decimal:128640. Unicode scalar values exclude surrogate code points. A visible character or emoji sequence may contain several scalars. Uniboard's character tiles insert one scalar at a time.

Browse or search Unicode blocks

Blocks group ranges of Unicode code points. Open Blocks to browse, or search names such as Arrows, Mathematical Operators or Greek and Coptic. Scroll through the paginated character grid, then open a tile for its name, code point and encoding details.

Insert symbols with the iOS keyboard

Enable Uniboard in keyboard settings and switch with the globe key. Its own search keys keep the query out of your document. Tap a result to insert the scalar where your cursor is. Space, return and delete are built into the keyboard.

Understand combining marks and invisible characters

Some characters combine with neighboring text, change layout, or have no visible glyph. Uniboard uses a dotted circle or an explanatory preview marker where useful, and copies or inserts only the original scalar. Check the details before using an unfamiliar character.

Why a new Unicode character may not render

Unicode data and fonts are different things. The catalog is built from the latest official development draft, but iOS fonts may not contain a glyph for a new assignment. A missing-glyph box does not necessarily mean the character is invalid. Draft assignments and names can change before the standard is finalized.
