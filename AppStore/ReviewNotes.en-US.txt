Uniboard 1.2 is an offline English and Unicode keyboard for iPhone and iPad. No login is needed. Core search and typing work offline. Full Access is optional.

SETUP
Add Uniboard in iOS Settings > General > Keyboard > Keyboards > Add New Keyboard. In Uniboard > Settings > Try Your Keyboard, focus the editor and hold the globe to select Uniboard.

DAILY INPUT
Literal QWERTY has a number row (removable in App Settings), three letter rows and taller matching keys. Tap Shift for one capital, double-tap for Caps Lock, or touch Shift and slide to a letter. Test accents, punctuation, double Space, Return and repeating Backspace. There is no autocorrect or prediction. U toggles the Unicode toolbar. App Settings controls one optional symbol bar or its search-bar replacement; there is no resize handle. iPad has stock-style modifiers and configurable compact/full ANSI landscape layouts; Numbers/Symbols and Hide Keyboard sit right of Space.

UNICODE SEARCH
Tap U and open Unicode/search. Search U+1F680 and tap the rocket result to insert its original scalar. Names, descriptions, block names, aliases and complete emoji are supported. Suzhou numerals finds U+3021 HANGZHOU NUMERAL ONE with its naming note. Move the query cursor and edit the middle: both Delete controls affect the query while search is focused, never the host document. Done returns to host typing while retaining the query/results. Results scroll horizontally in portrait and appear alongside query keys on wide/landscape layouts. Hold/hover a result to inspect without inserting. The bounded native Save button opens a page chooser; it never types into the host. Details remain scrollable, including for unsupported glyphs. Emoji insert as intact sequences.

PAGES AND GESTURES
Star beside Space opens the preferred page (Favorites by default) and returns to QWERTY. Hold Star to choose/manage pages. All saved pages and Recent support horizontal paging. Symbols is included. Create/name/reorder/edit pages inside the keyboard; saving asks for its destination. Opening Star preserves U/search visibility. Saved/Recent use rounded keys without code-point captions. Hold keys for variants or inspection.

App Settings sets Up, Down and Hold choices per character key; a tap always types the key. Defaults: Up mapped symbols/macOS Option; Down superscript, subscript, math and circled forms; Hold current-case accents. Candidates are unique across default groups. Move up/down while held, reverse without lifting, and slide sideways to select. Function keys retain standard actions. Unicode editions and optional fonts are app-only settings: 18 release default, 17/16 previous, 19 DRAFT. All catalogs are bundled offline. Unicode results are listed by code point.

PRIVACY
No typing, queries, accounts or analytics are collected. Shared on-device files contain app settings, configured keys and explicit Favorites, never document typing or queries. With Full Access OFF, app Favorites reach the keyboard and keyboard edits remain pending locally. Optional Full Access permits writing explicit Favorites back to Saved and light iPhone haptics; it does not enable network collection. Pages, recents and scratchpad stay local. Receiving apps handle inserted text. iOS uses its own keyboard in secure/phone fields; apps may disable custom keyboards.

OPTIONAL FONT DOWNLOADS
App Settings > Font Downloads offers Noto-first historic/symbol, rare Han, Seal and emoji packs, singly or via Download All. Downloads are explicit, cookie-free static file requests to GitHub’s release CDN; no typing, query or favorite data is sent. Files are size/SHA-256 verified before local App Group installation, excluded from backups, removable and usable offline without Full Access. Cancel keeps completed files; retry fetches only missing ones. Extra Unicode fonts defaults off. Try U+16A70 after the historic pack, or a rare Han character after its pack. A bundled preview face fixes 86 dotted-circle combining clusters.
