A daily English keyboard with full Unicode close at hand.

- Literal QWERTY with Shift/Caps Lock, accented-letter long presses, number/symbol pages and repeating Backspace.
- Custom symbol boards, a stock Symbols board, glyph-only keycaps, configurable long-press variants and a board chooser when saving.
- Favorites-first Star/back-arrow switching, with a configurable preferred board. Compact, equal key heights without blank space; U shows/hides the toolbar. A number row at four rows and a horizontally scrolling symbol strip at five.
- Clearer search text and cursor editing anywhere. Ascending code points by default, with whole-word matches before mid-word matches; saved sort choices persist.
- Portrait swipes add/remove one row on release, with simple ▲/▼ feedback and corrected height negotiation.
- Unicode 18 latest release by default, previous releases 17/16 and optional 19 DRAFT, selected only in app Settings. All four work offline in the keyboard without Full Access.
- Edition, optional preview fonts and the optional collapse key are controlled only in app Settings. The keyboard menu offers order and Open companion app.
- Matching rounded symbol keycaps; expanded symbol pages replace redundant digits with common symbols.
- App-only letter/number/symbol settings for long press, swipe up/down and ordered literal candidates; function keys keep their usual actions. Opposite-case letter flicks retain Shift and support horizontal choice selection.
- Wide iPad defaults to three letter rows, gray modifiers, blue Return, Tab/Caps Lock and down-flick number/symbol hints. Narrow windows retain compact keys.
