# Optional preview fonts

Extra Unicode fonts is off by default. The app's Setup switch and keyboard's Fonts menu save separate local preferences. No network, Full Access, font installation or process-wide registration is involved. The resolver opens bundled CGFont files only when the setting is enabled and Core Text reports a missing scalar glyph. Disabling it clears the resolver's caches. Text already rendered by native fallback, interface text, editors and all emoji entries keep system fonts. Insertion always uses the original Unicode text; the receiving app chooses its own fonts.

The pack contains unchanged [Noto Sans Symbols 2 v2.008](https://github.com/notofonts/symbols/releases/tag/NotoSansSymbols2-v2.008), [GNU Unifont 18.0.01 and Unifont Upper](https://unifoundry.com/unifont.html), in that priority. All are redistributed under their bundled SIL Open Font License 1.1 notices, available in Setup → Font licenses. GNU Unifont is a compact, monochrome specimen font with limited complex-script shaping. Noto supplies smoother symbols when native fonts lack them; it adds no unique scalar coverage to this pack.

`Fonts/manifest.json` pins source URLs, release versions, exact bytes and SHA256 hashes. Its 76,732-scalar union describes verified font coverage, not additional coverage beyond any particular iOS release. Coverage is restricted to assigned Unicode 18 graphic characters with real nonempty outlines. Unassigned characters, emoji, default-ignorables, private use, whitespace and blank glyphs are excluded. Unifont's outlines were checked against matching upstream bitmap rows, including exclusion of 13 assigned diagnostic hex boxes. This pack covers 329 Unicode-18-age scalars and does not cover all new scripts or future Unicode 19 draft assignments. Names, descriptions and properties remain available independently of glyph support.

The three fonts total 11,678,880 bytes (11.14 MiB) before compression, embedded independently in the app and extension. This is neither an App Store download size nor a runtime-memory measurement. Loading is lazy; the disabled path opens no font files. Each future font update must repeat the bitmap/outline and placeholder audit, update provenance and hashes, and pass `python3 Scripts/validate_fonts.py` plus native Core Text and keyboard tests. The monthly catalog update preserves this pinned pack; it does not infer font coverage from new Unicode assignments.

Native iOS 18.5 testing confirms recovery of BMP and supplementary specimens, including U+0558 and U+10940, and unchanged native emoji bitmaps. Some dotted-circle combining previews still lack a font that shapes the complete cluster: `◌ + U+1CF00` remains unsupported. The resolver rejects partial coverage rather than advertise recovery based only on the individual mark's outline. This is another reason the manifest's glyph count is not a promise of complete preview coverage.
