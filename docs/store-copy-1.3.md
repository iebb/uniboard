## en-US description (3402 characters)

Find Unicode characters, customize your keyboard and explore how text looks in different fonts. Uniboard combines a literal typing keyboard, personal symbol pages and offline character search for iPhone and iPad.

MAKE YOUR KEYBOARD YOURS
Edit letter, number and symbol keys, arrange your pages and drag keys into place. The default keyboard includes an editable number row. Configure tap, shifted tap, hold and swipe actions while keeping exact character sequences intact. Choose automatic capitalization by sentence, word or letter, follow the typing app’s preference, or turn it off. Some fields disable automatic capitalization.

SEARCH AND INSPECT
Search character names, aliases and Unicode blocks, or look up a code point such as U+1F680. A cached catalog index speeds up searches without indexing what you type. In Unicode search, tap keys to edit the query or hold a key to type it directly into your text.

Inspect the text shown in the keyboard preview: see code points, Unicode names, grapheme clusters, UTF-16 counts and normalization forms. Copy normalized text or UTF-8 and UTF-16 hexadecimal values without changing the input. Inspection doesn’t change your text or access the whole document.

MOVE THROUGH YOUR TEXT
Place the cursor in the font-rendered preview to move the real input cursor within the text the typing app exposes. Available context and cursor behavior depend on the app; this is not a replacement for its full text editor.

EXPLORE FONTS
Compare characters in fonts available to Uniboard. Filter accessible system, installed, bundled and downloaded fonts by family or style, and download Google Fonts on demand in the app. Availability can differ between the app and keyboard. Set preferred fonts for code points, ranges or Unicode blocks; missing or unsupported choices use fallback fonts. Font rules affect Uniboard’s rendering, not the font used by another app.

COPY TEXT AS A PICTURE
Copy the text visibly shown in the preview as an image with your chosen text and background colors, including transparency. Choose 1×, 2× or 3× resolution and see the resulting pixel dimensions. The image preserves its appearance without requiring the recipient to have the font. It pastes as a picture only where images are accepted, not as editable text.

TAKE YOUR SETUP WITH YOU
Export or import a TOML configuration with settings, layouts, favorites, font choices and Copy Image options. Edit your configuration in the app and validate changes before applying them. Review replacements and resets before applying edits or imports, then use Undo Last Configuration Change if needed. Font files and typing history aren’t included. Favorites and custom key text may be personal. Copy Image colors and scale chosen in the keyboard without Full Access aren’t included in the file.

LOCAL BY DESIGN
No account, ads or analytics. Character catalogs and search work offline; optional font downloads need an internet connection. Typing and searches aren’t sent to a server. Ordinary typing and text inspection don’t require Full Access; some clipboard and keyboard-to-app sharing features do.

Enable Uniboard in iOS Settings > General > Keyboard > Keyboards > Add New Keyboard, then hold the globe to select it. The interface and Unicode names and descriptions are English. Some apps and fields don’t allow custom keyboards. Font coverage and language-specific typing support vary.

## ja description (1795 characters)

Unicode文字を探し、キーボードを自分好みに整え、フォントによる見え方を比べられるアプリです。Uniboardは、文字をそのまま入力するキーボード、カスタム記号ページ、オフライン文字検索をiPhoneとiPadで利用できます。

画面とUnicodeの文字名・説明は英語です。名前による検索には英語を使い、コードポイントでも検索できます。

キーボードを自分好みに
英字・数字・記号キーを編集し、ドラッグで並べ替えられます。標準配列には編集可能な数字行が含まれます。タップ、Shift時のタップ、長押し、スワイプの動作を設定でき、結合文字や絵文字の文字列もそのまま保ちます。自動大文字入力は、文頭・単語の先頭・すべての文字から選ぶほか、入力先アプリの設定に従うか、オフにできます。一部の入力欄では自動大文字入力が無効になります。

文字を検索・確認
文字名、別名、Unicodeブロック、U+1F680などのコードポイントで検索できます。文字カタログの検索索引を端末内に保存し、検索を高速化。入力した文章は索引に含めません。Unicode検索中はタップで検索語を編集し、キーの長押しで検索語を変えずに入力先へ文字を送れます。

キーボードのプレビューに表示された文字について、コードポイント、Unicode名、書記素クラスタ、UTF-16コード単位数、正規化形式との一致を確認できます。正規化した文字列やUTF-8・UTF-16の16進数表記も、入力先の文章を変えずにコピーできます。確認だけで文章は変更されず、文書全体を読み取る機能ではありません。

プレビューからカーソルを移動
フォント表示されたプレビュー内で位置を指定すると、入力先の実際のカーソルが移動します。操作できる範囲は入力先アプリが提供する文字列に限られ、アプリによって動作や取得できる範囲が異なります。入力先の編集機能全体を置き換えるものではありません。

フォントを比較
Uniboardから利用できるシステム・インストール済み・同梱・ダウンロード済みフォントを、ファミリー名やスタイル名で絞り込めます。Google Fontsは必要なものをアプリ内でダウンロード。アプリとキーボードで使えるフォントは異なる場合があります。コードポイント、範囲、Unicodeブロックごとに優先フォントを設定でき、利用できないフォントや未対応の文字には代わりのフォントを使います。設定はUniboard内の表示に適用され、入力先アプリのフォントは変わりません。

文字を画像としてコピー
プレビューに見えている文字だけを画像にできます。文字色・背景色・透明背景を選び、1倍・2倍・3倍の解像度と実際のピクセル寸法を確認してコピー。相手が同じフォントを持っていなくても、画像として見た目を保てます。画像の貼り付けに対応するアプリで利用でき、編集可能な文字としては貼り付けられません。

設定をファイルで持ち運ぶ
設定、配列、お気に入り、フォントの選択、画像コピーのオプションをTOMLファイルで書き出し・読み込みできます。アプリ内で設定を直接編集し、適用前に内容を検証できます。編集内容や読み込みを適用する前に、置き換えや初期化される項目を確認できます。「Undo Last Configuration Change」で最後の設定変更を取り消すこともできます。フォントファイルや入力履歴は含まれません。お気に入りやカスタムキーの文字列には個人的な内容が含まれることがあります。フルアクセスなしでキーボード側から選んだ画像の色と倍率は、書き出すファイルに含まれません。

端末内で使う
アカウント、広告、アクセス解析はありません。文字カタログと検索はオフラインで使え、任意のフォントダウンロードには通信が必要です。入力内容や検索語をサーバーへ送りません。通常の入力と文字の確認にフルアクセスは不要ですが、一部のコピー機能やキーボードからアプリへの共有機能では必要です。

iOSの「設定」>「一般」>「キーボード」>「キーボード」>「新しいキーボードを追加」でUniboardを追加し、地球儀キーの長押しで切り替えます。一部のアプリや入力欄では他社製キーボードを使えません。フォントの対応範囲や、言語ごとの入力機能には制限があります。
