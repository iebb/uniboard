Uniboard is an offline English and Unicode keyboard for iPhone/iPad. No account/network/Full Access. Interface is English.

1. Add Uniboard in iOS Settings > General > Keyboard > Keyboards > Add New Keyboard. In Uniboard > Settings > Try your keyboard, focus the editor and hold the globe to select Uniboard.

2. Literal QWERTY has no autocorrect/prediction. Check Shift/Caps Lock, accents, number/symbol pages, capitalization, double-Space punctuation, Return and repeating Backspace. U toggles the initially hidden toolbar while retaining query/caret. Keys stay36pt; with digits visible Q–P down defaults use replacement symbols; digits appear at4 character rows and a scrolling symbol strip at5. The full symbol page replaces duplicate digits when English already shows them. Collapse defaults off. Toolbar uses Liquid Glass on iOS26+.

3. The star beside Space opens Favorites by default; its back arrow returns to QWERTY. Hold to switch/manage boards or set a preferred target. Temporary selection leaves that preference unchanged; deleting its custom target falls back to Favorites. Symbols is included. Saving a character/emoji asks for its destination. Saved/Recent keys have rounded surfaces without code-point captions.

4. App Settings > Customize keyboard keys independently remaps Tap, Shifted tap, Long press, Up, Down. Tap has one output; gestures have16. Default shifted single letters follow mapped case; custom Shifted tap is exact. Default, Off and Custom are distinct. Swipe a letter up for its opposite case and accents; slide left/right before lifting. Default case flicks retain Shift. Custom gesture text is literal, including combining sequences and whole emoji. Function/query/globe keys stay standard; default taps stay QWERTY. iPad portrait has three letter rows. App-only landscape presets offer stock/compact ANSI/ANSI with digits; Numbers/Symbols and Hide sit right of Space. Swipe-down mapping: standard/iPad/Off, with per-key overrides. Manual Shift changes ANSI symbols; Caps/automatic capitals keep digits literal.

5. Hold a board key for variants, Inspect or Edit. Add a variant from Unicode search; configuration must not type into the host. Browse-tile hold/hover inspects without insertion.

6. On iPhone portrait, swipe the grip up/down to add/remove one row on release, within screen limits. Only available steps show ▲/▼. There is no numeric preview/gauge. Taps/cancels retain height; landscape stays compact.

7. U > Unicode > Search. Enter U+1F680 and tap the rocket to insert its original scalar. Move the query cursor and edit the middle. Query keys/Space/Backspace leave the host unchanged. Done returns to English, retaining query/results/cursor. Held delete stops on release, resize, mode or document change.

8. Only app Settings selects Unicode18 release/default, previous17/16, or19 DRAFT. Reopen the keyboard after changes. U+10940 appears from17; U+0558 from18. Fonts/collapse default off and are app-only. Font licenses are in Settings. Fonts affect previews, not receiving apps. All catalogs are offline under Unicode License v3. Draft assignments may change.

9. Search suzhou numerals and inspect U+3021 HANGZHOU NUMERAL ONE; notes explain the naming issue. Emoji head shaking horizontally inserts U+1F642 U+200D U+2194 U+FE0F intact. Emoji ages differ from component Unicode ages. Ascending code points is default; whole-word matches precede mid-word. Saved sort persists. Unsupported glyphs retain properties; preview markers are never inserted.

The keyboard … menu contains only Order and Open companion app, with explicit Home Screen guidance if iOS rejects opening. No collection or remote typing/search. Boards, favorites, recents and scratchpad stay on-device. Shared files contain only app-authored settings/key choices, never document typing or queries. Receiving apps handle inserted text. iOS uses its keyboard in secure/phone fields; some apps disable custom keyboards.
