Uniboard is an offline Unicode character and complete emoji explorer with a custom keyboard for iPhone and iPad. No sign-in, account, purchase, network connection or keyboard Full Access is required. The interface and Unicode names/annotations are English; the Japanese storefront states this.

Version 1.1 fixes blurred search text, adds a steady target-height preview with resizing on release, and moves the height grip to the top edge without extra padding. Query text and caret use a quiet native key surface outside the glass compositor; adjacent controls retain Liquid Glass. On iOS 26 and later the toolbar uses Liquid Glass; older systems and Reduce Transparency have semantic fallbacks.

Keyboard test:
1. Settings > General > Keyboard > Keyboards > Add New Keyboard > Uniboard. Full Access is not requested. Open Uniboard > Setup > Try your keyboard, tap the editor and hold the globe key to select Uniboard.
2. In portrait, check that the placeholder and query text stay sharp, and the grip sits at the top edge. Drag the grip slowly and quickly up/down: a target-height preview follows the gesture while the keyboard stays steady. Release to apply the height once, between 220 and 420 points for browsing, capped for the display. Tap it to switch between compact and expanded heights. The browsing preference is saved locally. Landscape stays at 220 points; iPad retains its existing layout.
3. Tap search to expand the query keys. Enter U+1F680 and tap the rocket to insert only the original scalar at the host cursor. Tap or drag inside the query text to reposition its local cursor, then insert or delete in the middle. The host text must remain unchanged while editing a query.
4. Tap Done to fold the query keys: the query and filtered results remain available at the saved browsing height. Tap a result to insert it, tap the search text to resume editing, or Clear to show the full catalog. While folded, space/return/top-right repeating backspace edit the host normally; while searching, space/backspace edit only the query. Held delete must stop on release or when the search mode or receiving document changes.
5. Search "suzhou numerals" and hold U+3021. The official name remains HANGZHOU NUMERAL ONE; its section and Unicode notes explain the Suzhou naming issue. Inspect typed aliases, historical names, notes, related characters and numeric/case properties where supplied by Unicode. Holding or hovering never inserts text; Back closes details and Save adds a local favorite.
6. In the section menu select Emojis, clear the query and search "head shaking horizontally". Inserting it preserves U+1F642 U+200D U+2194 U+FE0F, including ZWJ and VS16.
7. Options contains Unicode 18 latest / Unicode 19 draft, numeric-version or code-point order, and Extra Unicode fonts. Fonts are optional and off by default; app and keyboard remember their own settings. Font licenses are under Setup.

Both Unicode editions and fully qualified emoji catalogs are bundled offline with provenance and Unicode License v3. Draft names/assignments may change; selecting a draft does not mean every entry is new. Original official names are preserved; formal name corrections are distinguished from informative aliases and NamesList notes. Example searches include infinity, arrows, U+1F680, 0x1F680, decimal:128640, and literal characters in the app.

Missing glyphs or separate emoji components reflect iOS font coverage. Names and properties remain readable; preview markers for invisible/combining characters are never inserted. Optional fonts change previews only, not receiving apps.

No user data is collected; there is no analytics/advertising SDK or remote typing/search service. Favorites, recents, preferences and scratchpad stay local. Receiving apps handle inserted text. iOS uses its own keyboard in secure/phone fields; some apps disable custom keyboards.
